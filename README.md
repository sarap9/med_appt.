Este laboratorio tiene como objetivo convertir una interfaz estática HTML/CSS en una aplicación dinámica e interactiva en React para la plataforma médica StayHealthy Inc. (med_appt).
Objetivo General
Migrar los módulos de la aplicación a una arquitectura de componentes reutilizables con React Router para la navegación y validaciones dinámicas en los formularios.
Resumen de Ejercicios del README

Ejercicio 1: Componentes de Navegación e Inicio

Crear la estructura de carpetas dentro de src/Components/ (Navbar y Landing_Page).

Convertir las estructuras HTML estáticas en componentes dinámicos JSX con sus respectivos archivos .css.

Configurar las rutas principales en App.jsx
Ejercicio 2: Formularios de Registro e Inicio de Sesión

Crear los componentes Sign_Up y Login dentro de sus carpetas correspondientes.

Añadir validaciones obligatorias requeridas por el cliente (como exigir exactamente 10 dígitos en el campo de teléfono de registro).

Conectar el estado del formulario con la API mediante fetch e integrarlo con sessionStorage.

Vincular todos los enlaces de la barra de navegación para que cambien de vista sin recargar la página.Ejercicio 3 / Entregables de Evaluación
